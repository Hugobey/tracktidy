Saturday afternoon, the USB is still empty, and the Beatport folder looks like a junk drawer. The first file is `track_final_v2_master(1).mp3`. Under it sits `04-track-04.mp3`, then a title with the producer's tag welded on. None of them tell you what you are about to play.

Rekordbox and Serato search the tags. Finder, File Explorer, and the little screen on a lot of players show the filename. When those two disagree, you stop trusting both and you start scrolling.

## Finder will not save the night

You can rename by hand. Right-click, type, hit return, next file. After a dozen promos the names get shorter, because you are bored and the set is tonight.

A rename tool that only swaps underscores is worse than slow. `track_final_v2` becomes `track final v2`, and the artist field is still empty. You wanted something you can read in a dark booth: `Artist - Title (124 BPM) [8A].mp3`.

A Bandcamp crate of unmastered WAV promos is a normal Friday. TrackTidy does not rename a folder in one shot, and it does not take WAV. Convert those, or leave them. A big MP3 cleanup is a queue. Same pattern, one file, then the next. You still look at each file. A bad template on 200 tracks ruins a night faster than a slow one.

## The pass I actually use

1. **Drop a single MP3.** The page reads it in the browser. If it is not an MP3, I leave it where it is.
2. **Fix the artist and the title first.** Then I apply a pattern I can scan: `Artist - Title (124 BPM) [8A]`.
3. **Read the preview before downloading.** If I would not say that name to another DJ, it is not done.

## Two names, so you can see the difference

| Messy original | Clean name |
| --- | --- |
| `12_track_name_MASTER_final_320.mp3` | `Artist - Track Name (124 BPM) [8A].mp3` |
| `unknown_artist_unmastered.mp3` | `Producer - Song Title (128 BPM) [4B].mp3` |

That second row is the shape you are aiming for. It is not a guess the page invented. If the tag never had an artist, you type the artist. The tool does not know who made the record.

The audio is not re-encoded. You are changing the label and the tags, not the master. If the title is still a promo URL, or the artist field is blank, fix the tags before you trust the filename.
