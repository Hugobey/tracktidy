If you download music packs, promo pools, or stems regularly, the folder looks like a landfill: `track_final_v2_master(1).mp3`, `04-track-04.mp3`, producer tags welded onto the title.

Messy names wreck the crate in Rekordbox, Serato, and Traktor. Search looks at the tags. A file list looks at the name. When those disagree, you scroll instead of playing.

<Callout type="tool-promo">
**Want to fix a file right now?** Open TrackTidy and clean one MP3 in the browser: tags, BPM, an estimated key, and a filename. No installation, no account, and the file stays on your machine.
</Callout>

## Why renaming in Finder kills prep

Right-click, type, enter, next file. A fresh pile of promos eats the hour. A desktop rename that only swaps underscores turns `track_final_v2` into `track final v2` and calls it done. It does not write `Artist - Title (124 BPM) [8A].mp3`, and it does not notice the artist field is empty.

TrackTidy does not rename a folder in one shot. It also does not take WAV. The workable version of a big cleanup is a queue: the same pattern, one MP3, then the next. You still look at each file. A bad template on 200 tracks is a worse night than a slow one.

## The pass, in the browser

1. **Open one MP3.** Drop a single file into the tool. It is read in the browser. If it is not an MP3, leave it.
2. **Set the name from the tags.** Clean the artist and title first, then use a pattern you can scan: `Artist - Title (124 BPM) [8A]`.
3. **Read the preview.** Compare the messy name with the new one. Download only when the name matches the track you meant.

## Before and after

| Messy original | Clean name |
| --- | --- |
| `12_track_name_MASTER_final_320.mp3` | `Artist - Track Name (124 BPM) [8A].mp3` |
| `unknown_artist_unmastered.mp3` | `Producer - Song Title (128 BPM) [4B].mp3` |

That second row is the target, not a guess the page invented. If the tag never had an artist, you type the artist. The tool does not know it.

The audio is not re-encoded. You are changing the label and the tags, not the master. When the title is full of a promo URL, or the artist field is empty, fix the tags before you trust the filename.
