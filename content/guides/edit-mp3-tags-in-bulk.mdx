## Why the info panel eats the hour

Finder and Explorer show you file properties, not a DJ tag form. You get one window, a comments box that may not be the frame your software reads, and no BPM sitting next to the title. So you switch to a player to hear whether this is the edit you wanted, then switch back, then do it again.

The switch is the tax. The tag change itself is a few words.

## The same junk, over and over

After a few pools you stop being surprised. A Beatport download and a Bandcamp promo fail in the same four ways. These show up constantly.

### A URL pretending to be the title

`Night Drive (Extended) [free dl: poolsite.com]` is `Night Drive (Extended Mix)`. The link is not the title. Take it out of the comment too, or the comment becomes the thing you read instead of the mix version.

### Three spellings of one artist

`ARTIST`, `Artist`, and `Artist feat. Someone` will not group. Decide once and write it down if you have to.

- Lead artist in the artist field: `Artist`
- Guests either in the title or after a comma, not both styles in the same crate

Future-you searches one string.

### A fake album

An album field set to the zip name, `Week_12_House_Pack`, makes a hundred unrelated tracks look like one release. Clear it, or put the real release name in.

### BPM and key left at zero

Sorting by tempo does nothing until the number is real. Fill BPM. Fill key if you mix harmonically, and use the same system on every file. If the promo arrived as an unmastered WAV, TrackTidy will not open it. Keep an MP3 for this pass.

| Before | After |
| --- | --- |
| Title: `Night Drive [free dl: poolsite.com]` | Title: `Night Drive (Extended Mix)` |
| Artist: `NORA VOSS feat DJ EXAMPLE` | Artist: `Nora Voss` |
| Album: `Week_12_House_Pack` | Album: cleared, or the real release |
| BPM: `0` | BPM: `118` |

## Stay in one folder

Don't bounce between genres. Finish the pile in front of you.

1. Sort the folder by name so the ugly files are obvious.
2. Open one MP3 in an editor that shows artist, title, album, genre, BPM, and key on one screen.
3. Strip the URL and the free-download text from the title and the comment.
4. Normalize the artist with the rule you already picked.
5. Fill BPM and key. Fold a detected 59 into 118 if that is the tempo you play.
6. Write a filename that matches the tags: `Artist - Title (118 BPM) [8A].mp3`. The rename pass is the one in [how to batch rename MP3 files online](/guides/batch-rename-mp3-files-online).
7. Save. Next file. Don't reopen a file you just saved unless the filename looks wrong.

If a file is the wrong edit, or not an MP3, skip it. Fixing tags on a mislabeled rip makes the mistake look official.

> Select-all is how one empty artist field becomes a folder of files named `( BPM).mp3`. Promo cleanup is repetitive. It is not identical. The extended mix and the radio cut need different titles.
