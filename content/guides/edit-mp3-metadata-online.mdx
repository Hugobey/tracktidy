The filename is what you see on a USB. The metadata is what Rekordbox and Serato search. I have had tracks with a perfectly tidy name and an empty artist field. Type the artist, get nothing back. The file was fine. The tag was the problem.

You do not need a desktop tagger for this. An MP3 already carries the text. A page in the browser can read those frames, let you change them, and write them back without re-encoding the audio.

## The fields that actually change a search

Leave the obscure frames alone unless you know you need them. These six are the ones I touch on a normal prep night, including the hour before a weekend club set.

| Field | Frame | What you use it for |
| --- | --- | --- |
| Artist | TPE1 | The string you type when you search |
| Title | TIT2 | The track name, without a promo URL |
| Album | TALB | Keeping a real release together |
| Genre | TCON | Filtering, if you actually filter by genre |
| BPM | TBPM | Sorting by tempo |
| Initial key | TKEY | Harmonic mixing, in one system |

**Artist.** Pick one spelling and stick to it. `ARTIST` and `Artist` will not sit together when you sort.

**Title.** The name of the track. `Night Drive (Extended) [free dl: poolsite.com]` should just be `Night Drive (Extended Mix)`.

**Album.** Useful when a release should stay together. Useless when it still says the name of the zip you downloaded on Tuesday.

**Genre.** Your word, not the store's. If you never filter by genre, leave it alone. An invented genre is just another thing to ignore.

**BPM.** A number you would actually play. `0` and a blank field both sort like junk.

**Initial key.** Camelot (`8A`) or musical key, whichever your software uses. Don't keep both systems in one crate or the harmonic groups split in half.

Comments are optional. If the comment is a promo paragraph, clear it. The software will show it, and it will not help you find the track.

## Why the search box comes back empty

DJ software indexes the tag. You search that index.

An empty artist means a search for the artist returns nothing, even when the filename contains the name. A title that still says `free download at poolsite.com` means you have to remember the URL to find your own edit. A BPM of 0 hides the track when you sort by tempo. A key written as `Am` in one file and `8A` in the next splits one harmonic group into two that don't look related.

Older files fail more quietly. Sometimes the artist text landed in the title. Sometimes an old ID3v1 field still holds a chopped-off name while the ID3v2 field is empty. The software shows one of them. You search for the other.

Running analysis again does not invent text that was never in the file. It can suggest a BPM and a key. It cannot know that the artist was misspelled.

## A pass that takes a minute

This is the online editor, one file at a time. You change the tags, then you download.

1. Open one MP3 and make sure it is the track you think it is. The wrong file with the right tags is a classic way to embarrass yourself later.
2. Read the artist and the title out loud. If you would not say it on a rider, rewrite it.
3. Set album and genre only when you will actually filter by them.
4. Set BPM from a detector, then fold an obvious half or double into the tempo you play. A 62 that is really 124 should be stored as 124 if that is how you browse.
5. Set the key you want stored. Treat the estimate as a suggestion. Your ear wins an argument with a key finder.
6. Clear the comment spam.
7. Write the file. Then [rename it from the cleaned tags](/guides/batch-rename-mp3-files-online), so the USB label and the search box finally say the same thing.

```
Before: Night Drive (Extended) [free dl: poolsite.com]
After:  Night Drive (Extended Mix)
```
